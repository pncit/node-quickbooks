## reviser — round 1

| ID | Disposition | Rationale (and, for Fixed, what changed) |
|----|-------------|-------------------------------------------|
| engineer-r1-f1 | Fixed | Replaced the `setTimeout(..., 20)` in case 4 with a deterministic settle chain. The hook now stores its own rejected promise in a closure variable (`hookPromise`), and the new `afterHookSettles(hookPromise, fn)` helper chains `Promise.resolve(hookPromise).catch(noop).then(() => setImmediate(fn))`. This waits deterministically for the hook's full promise chain (including the runtime's isolation `.catch`) to settle, then uses `setImmediate` to run after the `unhandledRejection` macrotask tick — no wall-clock sleep. All four tests pass at 8 ms. |
| engineer-r1-f2 | Fixed | The magic constant `20` is gone; it was eliminated by the f1 fix. No named constant is needed because no timer remains. |
| engineer-r1-f3 | Fixed | Introduced `afterHookSettles(hookPromise, fn)` as a single settle helper used by all four cases. Cases 1–3 pass `undefined` as `hookPromise` (degrades to one microtask drain + `setImmediate`, equivalent to the prior plain `setImmediate`). Case 4 passes its `hookPromise`. The inconsistency between `setImmediate` and `setTimeout` is eliminated; all four cases read uniformly. |
| engineer-r1-f4 | Fixed | Wrapped every deferred assertion block in `try { ...; done(); } catch (e) { done(e); }`. Assertion failures inside `afterHookSettles` and the synchronous-assertion blocks in the `refreshAccessToken` callbacks now route through `done(e)`, so mocha attributes the failure to the owning test rather than emitting an uncaught-exception event. |
| typescript-cop-r1-f1 | Fixed | Added `assert.notStrictEqual(callbackArgs, null, 'refreshAccessToken callback was never called')` as the first statement inside the case 4 `afterHookSettles` handler, before any indexing of `callbackArgs`. A future regression that prevents the callback from firing now produces a named assertion failure with a clear message rather than a `TypeError: Cannot read properties of null`. |
